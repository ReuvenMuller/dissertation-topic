# Initial must-read pool

This pool will provide a balanced orientation to modern AI and AI agents. It is intentionally empty until the reading-list selection step.

## Selection goals

The final pool should balance:

- foundational ideas and recent state of the art;
- agent architectures, reasoning, planning, memory, tool use, and multi-agent systems;
- evaluation, reliability, safety, and human interaction;
- influential papers and credible critical perspectives;
- surveys for orientation and primary papers for evidence.

## Guardrails

- Keep the initial core manageable—roughly 12–20 papers.
- Add an optional second tier for breadth.
- Note what each paper teaches that the others do not.
- Avoid filling the pool solely from citation counts, benchmark performance, or current hype.
