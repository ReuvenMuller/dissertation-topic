# Ideas and questions

This area holds ideas before they are mature enough to become candidate topics.

Use [idea-log.md](idea-log.md) for short observations. Create a separate card from [templates/idea-card.md](../templates/idea-card.md) when an idea keeps returning or needs serious development.

Useful raw material includes:

- a contradiction between papers;
- an assumption that is rarely tested;
- a weak or unrealistic evaluation method;
- a gap between deployed systems and academic benchmarks;
- a surprising connection between subfields;
- a problem you would still care about after the novelty fades.
