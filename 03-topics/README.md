# Candidate topics

A topic is more than a label. It is a developing argument that a research area is important, tractable, sufficiently open, and personally compelling.

When a topic begins to recur, copy `templates/topic-overview.md` into a new folder here as `README.md`. Give the folder a short, stable name such as `agent-evaluation`.

Each topic folder should eventually contain:

- `README.md` — scope, questions, evidence, and personal fit;
- `research-questions.md` — candidate questions and how they might be tested;
- `synthesis.md` — what the topic's papers collectively say.

Its paper queue belongs in `01-reading-pools/topics/<topic-name>.md`.
