# Inbox

Use this folder for fast, low-friction capture. Do not organize while you are trying to preserve a thought.

During triage, move each item to one of these destinations:

- a paper → `01-reading-pools/initial-must-read/` or a topic paper pool;
- a developed paper note → `02-paper-notes/`;
- a possible research direction → `03-topics/`;
- an idea or question → `04-ideas/`;
- a cross-paper observation → `05-synthesis/`.

Try to empty the inbox during the weekly review.
