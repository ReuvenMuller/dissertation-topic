# AI & AI Agents Dissertation Landscape

This repository is a working environment for exploring the AI and AI-agent research landscape, developing possible dissertation topics, and making an evidence-based topic choice.

Start with [START-HERE.md](START-HERE.md).

## Current focus

The first two active interests are [agent harness engineering](03-topics/agent-harness-engineering/README.md) and [enterprise agent workflows](03-topics/enterprise-agent-workflows/README.md). Their intersection—reliable, auditable agents for real industry workflows—is the current lead to investigate, not yet a chosen dissertation topic.

See the [interest map](03-topics/interest-map.md) for adjacent areas and cross-cutting questions.

## Workspace map

| Area | Purpose |
|---|---|
| `00-inbox/` | Fast capture before deciding where something belongs |
| `01-reading-pools/` | Initial must-reads and evolving topic-specific queues |
| `02-paper-notes/` | One structured note per paper |
| `03-topics/` | One folder per possible dissertation topic |
| `04-ideas/` | Research ideas, questions, hypotheses, and tensions |
| `05-synthesis/` | Cross-paper landscape maps and weekly synthesis |
| `06-decisions/` | Criteria and evidence for narrowing to a topic |
| `templates/` | Reusable note and review templates |

## Guiding principle

Do not optimize for reading the largest number of papers. Optimize for producing a clearer map of the field, sharper questions, and better-supported topic choices.
